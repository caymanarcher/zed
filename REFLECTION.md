The technique that I learned for my zed app was event delegation. It is much easier to create one listener for all of my recipe cards since the listener now will not get deleted with the old cards. The singular listener across all my cards can call for any recipes from the list and then see which was cicked to know which card to then open. It is much more directed and simplified than using a different listener for each recipe card, and if the amount of recipes grows in the future, it will already be simplified for the event listener to pull up the recipe card that was clicked on. 

With this new concept I implemented thanks to Claude, there were some parts of this project that required my own judgement and accuracy. For example, my recipes were all recipes that I use and the gray area is chosen by me based on what I believe can use more flexibility or not. I tried for one recipe to create it using Claude when I did not know how to word the instructions, but it did not fully understand where there was gray area or ability to change the recipe a bit. One of the main parts of this app is that it provides a real human perspective on where ingredients can be altered a bit and not so strict. AI is very rigid and unable to understand that recipes may say they need a certain amount of something, but, in reality, it can be altered to personal preference or just not that serious. Also, I had to rewrite most text that AI originally inputted for me in the first draft since it sounds AI-written and robotic. The filter buttons for how much gray area also did not make sense, so I had to alter those to my personal preference.
